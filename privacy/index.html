Политика обработки персональных данных

Эта политика относится к сайту-портфолио Данила Сергеевича Долматова. Вопросы об обработке данных можно направить на dolmateevich@yandex.ru.

Обращения

На сайте нет формы заявки и регистрации. Если вы напишете по почте или через мессенджер, Данил получит данные, которые вы сообщите в обращении, и контакт для ответа. Эти сведения используются для ответа, обсуждения проекта и, если стороны договорятся, заключения и исполнения договора. Переписка хранится в течение срока, необходимого для этих целей и выполнения применимых требований закона.

Настройки и внешние сервисы

Сайт сохраняет выбранную тему в локальном хранилище браузера. Эту настройку можно удалить в настройках браузера. Счётчики аналитики и рекламные трекеры в коде сайта не установлены.

Хостинг GitHub Pages, Google Fonts и CDN Тильды получают технические сведения при загрузке страницы или ресурсов, включая IP-адрес. Почта, мессенджеры и сайты по внешним ссылкам обрабатывают данные по своим правилам. Сведения о сборе данных GitHub Pages.

Защита данных и ваши права

Доступ к переписке ограничивается средствами доступа к почте и мессенджерам. Вы можете обратиться за сведениями об обработке своих данных, попросить уточнить их, прекратить обработку или удалить данные в случаях, предусмотренных законом. Для этого напишите на указанный выше адрес.
